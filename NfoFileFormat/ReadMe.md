> Reads, edits and writes the NFO metadata sidecar files that Kodi, TinyMediaManager and Jellyfin keep beside media, so a tool can manage that metadata without hand-rolling the XML.

## 📦 Installation

```bash
dotnet add package Hawkynt.NfoFileFormat
```

## ✨ Features

- **NFO File Parsing**: Parse existing NFO files to extract media metadata.
- **Metadata Manipulation**: Modify the contents of NFO files programmatically.
- **NFO File Generation**: Create new NFO files with customized metadata.
- **NFO File Updating**: Update existing NFO files with modified metadata.

## 🚀 Quick start

```csharp
using Hawkynt.NfoFileFormat;

class Program {
  static void Main() {
    var nfoFile = NfoFile.Load("path_to_nfo_file.nfo");

    // Access metadata
    Console.WriteLine(nfoFile.Title);
    Console.WriteLine(nfoFile.Year);

    // Modify metadata
    nfoFile.Title = "New Title";
    nfoFile.Save("path_to_modified_nfo_file.nfo");
  }
}
```

## 🔌 Dependencies

None beyond the base class library.

## ⚠️ Limitations

- NFO is a loose convention rather than a specification: media managers disagree on which elements they write and read. This library covers the common movie/episode element set; fields a particular tool invents are not modelled.
- Files are loaded whole; there is no streaming API for very large NFOs.
